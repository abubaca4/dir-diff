# dir-diff

**dir-diff** — это высокопроизводительная многопоточная утилита командной строки на Rust, предназначенная для глубокого сравнения двух директорий и автоматического извлечения изменённых или новых файлов в отдельную папку. 

Изначально инструмент создавался для генерации легковесных «патчей» для игр на движке **Ren'Py** (например, между разными версиями игры или при портировании локализаций/модов). Утилита позволяет быстро вычленить только те ассеты и скрипты, которые были добавлены или изменены, чтобы не распространять весь дистрибутив целиком.

## Особенности

- ⚡ **Максимальная скорость:** Параллельное сканирование, сравнение и копирование файлов за счет использования `rayon`.
- 🔍 **Умное хэширование:** Использование криптографически безопасного и сверхбыстрого алгоритма `blake3` для побайтового сравнения неграфических файлов.
- 🖼️ **Сравнение изображений (SSIM):** Поддержка метрики структурного сходства (SSIM) для изображений (`png`, `jpg`, `webp` и др.). Если изображения пережаты в новой версии (например, при локализации), но визуально идентичны, утилита может проигнорировать их при заданном пороге `--ssim`, экономя место в патче.
- 🚀 **Оптимизация памяти:** Использование кастомного аллокатора `mimalloc` для снижения накладных расходов при работе с большим количеством мелких файлов (типично для распакованных `.rpa` архивов).

## Cборка

Убедитесь, что у вас установлен [Rust и Cargo](https://rustup.rs/).

```bash
git clone [https://github.com/abubaca4/dir-diff.git](https://github.com/abubaca4/dir-diff.git)
cd dir-diff
cargo build --release
```
Исполняемый файл будет находиться по пути: `target/release/`

## Использование

Базовый синтаксис:

```bash
dir-diff <СТАРАЯ_ПАПКА> <НОВАЯ_ПАПКА> <ПАПКА_ДЛЯ_ПАТЧА> [ФЛАГИ]
```

### Аргументы

- `<dir1>` - Исходная (старая) папка.
- `<dir2>` - Целевая (новая) папка.
- `<dir3>` - Выходная папка. Сюда будут скопированы все новые и изменённые файлы из `<dir2>` с сохранением структуры директорий.
- `--ssim <ЗНАЧЕНИЕ>` - Целевой порог схожести для изображений (от `0.0` до `1.0`). Если не задан, применяется строгое побайтовое сравнение (или 100% совпадение пикселей).

### Флаги для вывода в консоль
По умолчанию утилита выводит только итоговую статистику. Вы можете включить подробный вывод нужных категорий файлов:
- `-a, --add` - Вывести список новых (добавленных) файлов.
- `-r, --replace` - Вывести список изменённых файлов.
- `-d, --del` - Вывести список удалённых файлов (файлы, которые есть в старой папке, но отсутствуют в новой).

## Примеры
1. **Создание патча для Ren'Py игры:**
Сравнение оригинальной английской версии (`game_v1_en`) и русифицированной (`game_v1_ru`), сохранение разницы в папку `ru_patch`.
```bash
dir-diff ./game_v1_en ./game_v1_ru ./ru_patch
```
2. **Сравнение с учетом сжатия изображений:**
Допустим, в новой версии картинки были прогнаны через оптимизатор (разные хэши и размер), но визуально не изменились. Используем порог SSIM 0.95, чтобы такие картинки не попали в патч:
```bash
dir-diff ./game_v1 ./game_v2 ./update_patch --ssim 0.95
```
3. **Подробный лог удаленных и добавленных файлов:**
```bash
dir-diff ./old_build ./new_build ./diff_output --add --del
```
## Как это работает под капотом
1. **Сканирование:** Параллельно строятся деревья относительных путей для обеих папок.
2. **Фильтрация:** Файлы распределяются на добавленные, удаленные и кандидаты на изменение.
3. **Оптимизированное сравнение:**
    - Сначала сравнивается размер файлов. Если он разный — файлы точно изменены.
    - Если это изображения и передан флаг `--ssim` — происходит декодирование и сравнение структурного сходства (SSIM).
    - Для всех остальных файлов параллельно вычисляется `blake3` хэш через потоковое чтение (блоками по 64 КБ).
4. **Копирование:** Все измененные и добавленные файлы параллельно копируются в выходную директорию с воссозданием необходимого дерева папок.
